# Proyecto Blockchain PHP

This project is a web application with a PHP backend and a JavaScript frontend. It includes a blockchain implementation, user authentication, a YouTube video gallery, and a to-do list.

## Features

*   Blockchain with Proof of Work
*   User Registration and Login
*   Email and Phone Verification
*   YouTube to iFrame Converter
*   To-Do List
*   AJAX API

## Setup

1.  **Web Server**: Set up a web server with PHP and a MySQL database.
2.  **Database**: Create a database and import the `database.sql` file (to be created).
3.  **Configuration**: Update the database credentials in `api/config.php` (to be created).

## Running the Application

1.  Navigate to the project directory in your web browser.
2.  Register a new user or log in with an existing account.
