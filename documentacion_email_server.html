Guía: Configurar Servidor de Correo Local para PHP mail() en Zorin OS 17.3 Pro

Esta guía te mostrará cómo configurar un Agente de Transferencia de Correo (MTA) en tu Zorin OS 17.3 Pro para que PHP pueda utilizar la función mail() y enviar correos electrónicos, retransmitiendo a través del servidor SMTP de Gmail. Esto es esencial para probar funcionalidades como la verificación de correo electrónico en tu aplicación local.

Advertencia: Esta configuración es para entornos de desarrollo local y pruebas. No es adecuada para un servidor de correo en producción. Los correos enviados pueden terminar en la carpeta de spam del destinatario.

Paso 1: Generar una Contraseña de Aplicación de Google

Si utilizas una cuenta de Gmail con la autenticación de dos factores (2FA) activada (lo cual es muy recomendable), necesitarás generar una "Contraseña de Aplicación" para que Postfix pueda autenticarse con el servidor SMTP de Gmail.

  1. Ve a tu Cuenta de Google.
  2. En el menú de navegación izquierdo, haz clic en Seguridad.
  3. En la sección "Cómo inicias sesión en Google", haz clic en Contraseñas de Aplicación. Es posible que tengas que iniciar sesión de nuevo.
  4. Si no ves esta opción, asegúrate de que la verificación en dos pasos esté activada.
  5. En la parte inferior, en "Seleccionar aplicación" y "Seleccionar dispositivo", elige Correo y Otro (nombre personalizado) respectivamente. Dale un nombre como "Postfix Zorin".
  6. Haz clic en Generar.
  7. Se te proporcionará una contraseña de 16 caracteres (por ejemplo, abcd efgh ijkl mnop). Copia esta contraseña; la necesitarás más adelante y solo se mostrará una vez.

Paso 2: Instalar y Configurar Postfix

Postfix es un MTA popular y fácil de configurar. Lo usaremos para reenviar correos a través de Gmail.

  1. Abre una terminal (Ctrl + Alt + T) e instala Postfix y sus dependencias necesarias:

    sudo apt update
sudo apt install postfix mailutils libsasl2-2 ca-certificates libsasl2-modules

  2. Durante la instalación de Postfix, se te harán algunas preguntas de configuración. Selecciona las siguientes opciones:

    • General type of mail configuration: Internet Site
    • System mail name: Tu dominio (ej. ejemplo.com, o simplemente tu nombre de host si no tienes uno).
    • Root and postmaster mail recipient: Deja en blanco o tu usuario de sistema.
    • Other destinations to accept mail for: Deja como está (vacío).
    • Force synchronous updates on mail queue? No
    • Local networks: Deja como está.
    • Mailbox size limit (bytes): 0 (ilimitado)
    • Local address extension character: +
    • Internet protocols to use: all (o ipv4 si estás seguro de que solo usarás IPv4)

  3. Edita el archivo de configuración principal de Postfix:

    sudo nano /etc/postfix/main.cf

  4. Añade o modifica las siguientes líneas al final del archivo. Reemplaza tu_email@gmail.com con tu dirección de Gmail y your_domain.com con el nombre de tu sistema o dominio si es diferente:

    # Configuración para usar Gmail como relay SMTP
relayhost = [smtp.gmail.com]:587
smtp_use_tls = yes
smtp_sasl_auth_enable = yes
smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd
smtp_sasl_security_options = noanonymous
smtp_tls_CAfile = /etc/ssl/certs/ca-certificates.crt
smtp_generic_maps = hash:/etc/postfix/generic

  5. Guarda y cierra el archivo (Ctrl + O, Enter, Ctrl + X).

Paso 3: Configurar Credenciales de Gmail

Ahora crearemos el archivo que contendrá tu dirección de Gmail y la contraseña de aplicación generada en el Paso 1.

  1. Crea y edita el archivo de credenciales:

    sudo nano /etc/postfix/sasl_passwd

  2. Añade la siguiente línea, reemplazando tu_email@gmail.com y TU_CONTRASEÑA_DE_APLICACION_DE_GMAIL:

    [smtp.gmail.com]:587    tu_email@gmail.com:TU_CONTRASEÑA_DE_APLICACION_DE_GMAIL

  3. Guarda y cierra el archivo.

  4. Crea el archivo `generic` que mapeará tu usuario local a tu dirección de Gmail para los correos salientes:

    sudo nano /etc/postfix/generic

  5. Añade la siguiente línea, reemplazando tu_usuario_local (tu nombre de usuario en Zorin OS) y tu_email@gmail.com:

    tu_usuario_local    tu_email@gmail.com

  6. Guarda y cierra el archivo.

  7. Establece permisos correctos para el archivo de credenciales y crea la base de datos de Postfix:

    sudo chmod 600 /etc/postfix/sasl_passwd
sudo postmap /etc/postfix/sasl_passwd
sudo postmap /etc/postfix/generic

Paso 4: Configurar PHP (php.ini)

Necesitamos indicarle a PHP que utilice Postfix para enviar correos.

  1. Localiza tu archivo php.ini. Puede variar dependiendo de tu instalación de PHP (ej. Apache, Nginx con PHP-FPM). Una forma común de encontrarlo es crear un archivo info.php con <?php phpinfo(); ?> y buscar "Loaded Configuration File".

    Las ubicaciones comunes incluyen:

    • /etc/php/8.x/apache2/php.ini (para Apache)
    • /etc/php/8.x/fpm/php.ini (para Nginx con PHP-FPM)
    • /etc/php/8.x/cli/php.ini (para scripts de línea de comandos, no afecta al servidor web)

  2. Edita el php.ini correspondiente a tu servidor web (ej. Apache2 o FPM):

    sudo nano /etc/php/8.x/apache2/php.ini   # O la ruta correcta

  3. Busca la sección [mail function] y asegúrate de que la línea sendmail_path apunte a la ruta correcta de Postfix. Descomenta la línea si está comentada (quitando el `;` al inicio):

    sendmail_path = /usr/sbin/sendmail -t -i

  4. Guarda y cierra el archivo.

Paso 5: Reiniciar Servicios

Para que los cambios surtan efecto, debes reiniciar Postfix y tu servidor web (Apache o PHP-FPM si usas Nginx).

  1. Reinicia Postfix:

    sudo systemctl restart postfix

  2. Reinicia tu servidor web:

    • Para Apache: 
      sudo systemctl restart apache2
    • Para Nginx con PHP-FPM: 
      sudo systemctl restart php8.x-fpm   # Reemplaza 8.x con tu versión de PHP (ej. php8.1-fpm)
sudo systemctl restart nginx

Paso 6: Probar la Configuración

Finalmente, puedes probar si todo funciona creando un pequeño script PHP.

  1. Crea un archivo llamado test_mail.php en tu directorio web (ej. /var/www/html/ o dentro de tu proyecto).

    sudo nano /var/www/html/test_mail.php

  2. Añade el siguiente código, reemplazando tu_email_destino@example.com con una dirección de correo donde puedas verificar la recepción:

    <?php
$to      = 'tu_email_destino@example.com';
$subject = 'Prueba de PHP mail() desde Zorin OS';
$message = 'Hola! Este es un correo de prueba enviado desde tu servidor local en Zorin OS usando PHP mail().';
$headers = 'From: tu_email@gmail.com' . "\r\n" . 
           'Reply-To: tu_email@gmail.com' . "\r\n" . 
           'X-Mailer: PHP/' . phpversion();

if(mail($to, $subject, $message, $headers)) {
    echo "Correo enviado con éxito a $to";
} else {
    echo "Fallo al enviar el correo.";
}
?>

  3. Guarda el archivo y ábrelo en tu navegador (ej. http://localhost/test_mail.php).

  4. Verifica la bandeja de entrada (y la carpeta de spam) de la dirección de correo destino.

¡Felicidades! Ahora tu Zorin OS debería ser capaz de enviar correos electrónicos usando la función mail() de PHP.
